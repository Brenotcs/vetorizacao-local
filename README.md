# 🎨 Vetorizador Colorido Minimalista

Uma ferramenta web leve, executada inteiramente no navegador para converter imagens rasterizadas (**PNG**, **JPG**) em vetores limpos e coloridos (**SVG**).

## 🚀 Funcionalidades
* **100% Local e Privado:** Processado diretamente no teu navegador, sem enviar imagens para servidores externos.
* **Controle de Cores:** Seletor de paleta (4, 8, 16 ou 32 cores) para eliminar sombras indesejadas e degradês poluídos.
* **Traçado Liso (Anti-serrilhado):** Algoritmo integrado com desfoque de bordas (`blurradius`) para remover o efeito pixelado e entregar curvas limpas e fluidas.
* **Redimensionamento Automático:** Otimiza imagens pesadas antes do processamento para garantir velocidade e evitar travamentos.

## 🛠️ Tecnologias Utilizadas
* **HTML5 / CSS3** (Interface minimalista e responsiva)
* **JavaScript (Vanilla)**
* **ImageTracer.js** (Motor de vetorização e análise de pixels)

## 💻 Como Usar (Localmente)
1. Clona ou descarrega este repositório para o teu computador.
2. Certifica-te de que tens os ficheiros `index.html` na mesma pasta.
3. Faz duplo clique no ficheiro **`index.html`** para o abrir em qualquer navegador moderno (Chrome, Edge, Firefox, etc.).
4. Seleciona a tua imagem, escolhe a quantidade de cores desejada e clica em **Converter para Vetor** para descarregar o ficheiro `.svg` instantaneamente!
